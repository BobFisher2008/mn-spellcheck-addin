Монгол үг шалгагч

Microsoft Word, Outlook-д зориулсан монгол (кирилл) үгийн алдаа шалгагч · Mongolian spellcheck for Word and Outlook

Энэ өгүүлбэрт алдаатаай үг байна. Хуучин бичлэг: авилга, товъёг. Санал: алдаатай · авлига · товьёг — «Монгол хэлний зөв бичих дүрмийн журамласан толь» (2018)-ийн дагуу.

Суулгах · Install

Word (Windows)

Суулгагчийг татаж ажиллуулна. Администраторын эрх шаардахгүй.

Суулгагч татах

Windows «Windows protected your PC» гэвэл: More info → Run anyway (гарын үсэггүй туршилтын хувилбар).

Word (web, Mac)

  1. manifest-word.xml татах
  2. Word: Home → Add-ins → More Settings → Upload My Add-in
  3. Татсан файлаа сонгоно

Outlook

  1. manifest-outlook.xml татах
  2. aka.ms/olksideload → My add-ins → Custom Addins → Add from File
  3. Шинэ захидал бичих үед «Check Mongolian»

Байгууллагын бүх ажилтанд: Microsoft 365 admin center → Integrated apps-аас хоёр manifest-ийг байршуулбал хэрэглэгч юу ч хийх шаардлагагүй.

Нууцлал · Privacy

Бичвэрийг зөвхөн таны компьютер дээр шалгана. Энэ сайтаас зөвхөн программ болон толийн файлыг нэг удаа татна; баримт, захидлын агуулгыг хаашаа ч илгээхгүй, хадгалахгүй.

All checking runs locally inside Word/Outlook. This site only serves the program and the dictionary files; document and e-mail text is never sent anywhere.
